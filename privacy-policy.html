Summary

Satori Tab does not operate a server. There is nowhere for your data to go except your own device and, if you turn on Chrome sync, your own Google Account. We — the developer — never receive, see, or store any of it.

Satori Tab is a new-tab dashboard extension for Google Chrome. It shows customizable widgets — clocks, notes, a task list, bookmarks, a news reader, ambient soundscapes, focus timers, and search — on every new tab you open. This policy explains what information Satori Tab touches to do that, where it lives, and what it never does.

What Satori Tab stores, and where

Everything Satori Tab saves is written using Chrome's own extension storage APIs, on your device:

  • Local storage (chrome.storage.local): your widget layout, notes, to-do items, habit tracker entries, bookmarked speed-dial shortcuts, news feed subscriptions, and app preferences.
  • Synced storage (chrome.storage.sync): the same categories of settings, mirrored across your signed-in Chrome browsers through Google's own sync infrastructure — not through any server we operate. This only happens if Chrome sync is enabled on your device; it's a setting you control in Chrome itself, not inside Satori Tab.
  • Local cache (IndexedDB): recently fetched news articles, cached on-device so the News Feed widget loads quickly and works offline for a while. This is disposable cache, not account data.

None of the above is transmitted to any server operated by Satori Tab's developer, because no such server exists.

Satori Tab's use of any information obtained through Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

What Satori Tab never does

  • We never sell, rent, or trade your data — there is no data of yours in our possession to sell.
  • Satori Tab contains no analytics SDK, no crash-reporting service, no advertising network, and no third-party tracking script of any kind.
  • Satori Tab never reads the content of pages you browse outside its own new-tab dashboard.
  • Satori Tab never asks for, stores, or transmits passwords, payment details, or government ID information.

Permissions, in detail

Chrome requires every capability an extension might use to be declared up front. Here is what each declared permission is for and, importantly, what it is not used for:

  • storage / unlimitedStorage: saving your widgets and settings as described above.
  • bookmarks: read and organize your existing Chrome bookmarks inside the Bookmarks drawer and Speed Dial widget. Satori Tab can create, edit, or remove bookmarks only when you take an explicit action to do so (e.g. adding a shortcut to Speed Dial).
  • tabs / tabGroups / sessions: let dashboard widgets show, search, and switch to your currently open tabs, tab groups, and recently closed sessions. Satori Tab does not read the content of those tabs — only metadata Chrome exposes, like title and URL.
  • alarms: schedules a periodic background check for new articles in the feeds you've subscribed to, so the News Feed widget stays current without you having to manually refresh it.
  • notifications: shows a native Chrome desktop notification for things you've explicitly scheduled inside Satori Tab — a focus-timer session ending, a habit reminder, or an alarm you've set. Satori Tab only shows a notification for something you configured yourself; it never sends any notification on its own initiative.
  • favicon: used to fetch site icons shown next to bookmarks, tabs, and news sources — a purely visual lookup, not page content.
  • scripting: used for two things. First, alongside the favicon lookup above. Second — only if you explicitly turn on the optional "Show alarm on any site" setting — Satori Tab injects a small, self-contained alarm popup (snooze/dismiss controls and a sound) into your current tab so an alarm you set can still reach you if you're not on the Satori Tab new-tab page when it fires. This injected popup reads and changes nothing on the page it appears over; it draws its own isolated UI on top and is removed the moment the alarm is dismissed or snoozed.
  • identity / identity.email: reads the name and email already associated with your signed-in Chrome profile, non-interactively, so the dashboard can greet you by name and so your synced settings are correctly scoped to your account. This information is read locally and is never transmitted anywhere by Satori Tab, including to us.
  • Host permissions (fixed list of news, weather, and search domains): Satori Tab's News Feed widget fetches articles directly from each publisher's own server over HTTPS, entirely from your browser — never proxied through infrastructure we control. The Weather widget queries Open-Meteo and OpenStreetMap's geocoding service directly. The search bar queries Google's or DuckDuckGo's public suggestion endpoints directly. In every case, your browser talks straight to that third party; we're not in the middle and don't see the traffic.
  • Optional host permission (any site): Chrome only grants this after you explicitly opt in, for one of two features — adding a custom RSS/Atom feed URL not already in Satori Tab's built-in list, or turning on "Show alarm on any site." Declining the prompt simply means that one feature stays off; everything else in Satori Tab works normally either way.

Third-party requests Satori Tab makes on your behalf

Because Satori Tab has no backend, every outbound request it makes happens directly from your browser to the relevant third party, using only the minimum information that request requires (for example, a city name to fetch a weather forecast, or a search query to fetch autocomplete suggestions). These include:

  • News and media publishers you subscribe to, to fetch their public RSS/Atom feeds.
  • Open-Meteo and OpenStreetMap Nominatim, for weather data and place lookups.
  • Google and DuckDuckGo, for search-suggestion autocomplete.
  • Google's own account-sync infrastructure, if you have Chrome sync enabled.

Each of these services has its own privacy practices, which we don't control. We chose services here that don't require you to create an account or share a persistent identifier with them.

Ambient soundscapes

Satori Tab's soundscape widget plays ambient audio (rain, waves, campfire, and similar) entirely on-device, using audio files bundled directly inside the extension. Playing a sound doesn't contact any server, log any listening activity, or leave your device. Two tracks are generated locally using the Web Audio API and involve no audio files at all.

Support & donations

Satori Tab includes an optional "Support Satori Tab" button that links out to Ko-fi, a third-party donation platform. Clicking it opens Ko-fi in a new tab — Satori Tab does not collect, process, or store any payment information itself, and no card or billing details are ever entered inside the extension. Whatever happens on Ko-fi's own site is governed by Ko-fi's privacy policy, not this one. Supporting the project is entirely voluntary: every feature in Satori Tab is fully free and functional whether or not you ever click this button.

Retention and deletion

Because your data lives in Chrome's own storage, you control its retention directly: uninstalling Satori Tab removes its local data from your device. Data mirrored through Chrome sync follows Chrome's own sync retention, which you can clear from Chrome's sync settings independent of Satori Tab. The News Feed cache can be cleared at any time from within Satori Tab's own settings.

Children's privacy

Satori Tab is not directed at children and does not knowingly collect personal information from anyone. Because Satori Tab collects no personal information on any server in the first place, there is no server-side data to distinguish by age.

Changes to this policy
